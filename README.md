# 🏠 Cloud-Based Smart Hostel Management System

A modern cloud-based hostel management system designed to simplify
student, room, attendance, fee, complaint, visitor and leave management.



## ✨ Features

- 👨‍🎓 Student Management
- 🏠 Room Management
- 📋 Attendance Management
- 💰 Fee Management
- 📝 Complaint Management
- 🚪 Visitor Management
- 📨 Leave Management
- 📢 Notice Management
- 🔔 Notifications
- 📊 Dashboard
- ☁️ Cloud-based architecture
- 📱 Responsive UI

## 🛠️ Technologies

- React.js
- TypeScript
- Vite
- Supabase
- Vercel
- Tailwind CSS
- GitHub
